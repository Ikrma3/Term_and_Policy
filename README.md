## Adding an app

1. Create a folder (e.g. `newapp/`) with `privacy.html` and `terms.html`, using an existing
   app's pages as a template. Link the shared stylesheet as `../style.css`.
2. Write the policy for what that app actually collects; each app needs its own.
3. Add the app to `index.html` and to the table above.

When you change a page, update its "Effective date". The old root `privacy.html` /
`terms.html` redirect to SkinScan's pages.
